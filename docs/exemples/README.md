# Exemples des fiches TVM

- [Fiche d’intervention fictive](fiche_intervention_fictive.pdf)
- [Fiche de suivi fictive](fiche_suivi_fictive.pdf)

Ces deux PDF ont été générés par le code de l’application à partir d’enregistrements de démonstration entièrement fictifs. Ils illustrent les cadres, rubriques, cases et annexes ; ils ne concernent aucun équipement ni client réel et ne constituent ni visa, ni signature recueillie.

Le PDF original de l’utilisateur, son logo incorporé, ses coordonnées et les données de ses clients ne sont pas inclus dans ces exemples. Dans l’application, les fiches sont générées depuis les dossiers autorisés à l’instant du téléchargement.
