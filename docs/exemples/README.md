# Exemples des fiches TVM

- [Fiche de suivi fictive](fiche_suivi_fictive.pdf)

Ces PDF ont été générés par le code de l’application à partir de données entièrement fictives. Ils illustrent les cadres, rubriques, cases et annexes ; ils ne concernent aucun équipement ni client réel et ne constituent ni visa, ni signature recueillie. Le montant et le taux de TVA du devis sont des exemples ; l’application exige un taux explicitement renseigné.

Les coordonnées légales de TVM ne sont pas configurées dans cet exemple ; le devis le signale. Le document ne constitue ni facture, ni preuve d'accord ou de paiement, ni validation complète de conformité juridique ou commerciale.

Le PDF original de l’utilisateur, son logo incorporé, ses coordonnées et les données de ses clients ne sont pas inclus dans ces exemples. Dans l’application, les fiches sont générées depuis les dossiers autorisés à l’instant du téléchargement ; les devis reproduisent les données figées lors de leur émission.
